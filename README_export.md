# Export Request 
This export request covers one code repository: normalization-cms. This repository has been packaged separately as its own ZIP file. The archive contains code only and do not include any data files. This is a codebase developed to process CMS Medicare and Medicaid data. 

The contents have been reviewed to confirm that they do not expose file paths, identifying information, or other known security or privacy vulnerabilities. The purpose of this export is to support development of the companion paper describing this process. Specifically, the repositories are being shared as reference material to inform the manuscript drafting. 

These code exports are not intended to be executed in their current form. Instead, we would like to export them solely to enable review of the code structure, workflow, and implementation details relevant to the paper.

Each ZIP file also includes a README with additional information about the repository’s structure, components, and contents.
